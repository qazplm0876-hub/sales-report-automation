권장 방식은 분석월별 폴더를 만들어 원본을 보관하는 것입니다.

예: input/202608/ 안에 2026년 8월 기준 원본 9개를 넣고 RUN_ANALYSIS.bat을 실행합니다.
프로그램은 가장 최신의 YYYYMM 폴더를 자동 선택하고, 공식표 제목의 분석월과 폴더명이 다르면 중단합니다.
따라서 지난달 파일을 삭제하거나 분석월을 입력할 필요가 없습니다.

기존처럼 input 폴더 바로 아래에 파일을 넣는 방식도 계속 지원합니다.

각 월별 폴더에는 통합형 기준으로 아래 엑셀 9개를 넣어 주세요.

[권장 구성: 총 9개]
1. 사업계획대비매출실적분석 공식표 1개
2. 전년 누계파일 1개 (예: 20257월누계.xlsx)
3. 당해 누계파일 1개 (예: 20267월누계.xlsx)
4. 전년·당해 거래가 함께 있는 인수처 통합 파일 6개
   - 합섬 수출·내수 각 1개
   - 스텐 수출·내수 각 1개
   - 제강 수출·내수 각 1개

예: 거래처 정보 포함 25-26 제강(내수).xlsx
파일명은 고정하지 않으며 내부 연도·부문·내수/수출 구조로 자동 판별합니다.
공식표·전년 누계파일·당해 누계파일·인수처 통합 파일 6개는 모두 해당 분석월 기준 누계 최신본을 넣습니다.

[기존 분리형: 총 15개]
통합 파일 대신 아래 당해 6개와 전년 6개를 나누어 넣어도 됩니다.
- 당해: 1.xlsx, 1_내수.xlsx, 2.xlsx, 2_내수.xlsx, 3.xlsx, 3_내수.xlsx
- 전년: 25_1.xlsx, 25_1_내수.xlsx, 25_2.xlsx, 25_2_내수.xlsx, 25_3.xlsx, 25_3_내수.xlsx

연도가 바뀌면 전년 파일의 접두어도 바꿉니다. 예: 2027년 분석은 26_1.xlsx.
같은 부문의 통합형과 분리형을 함께 넣으면 중복으로 판정되므로 둘 중 하나만 사용합니다.
한 파일에 여러 시트가 있으면 분석 대상 연도의 거래행이 가장 많은 원자료 시트를 자동 선택합니다.
원본 엑셀은 .gitignore에 의해 GitHub에 업로드되지 않습니다.
