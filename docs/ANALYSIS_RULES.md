# 분석 및 검산 규칙

## 1. 입력자료 역할

| 자료 | 사용 용도 | 사용하지 않는 용도 |
|---|---|---|
| 전년·당해 누계파일 2개 | 전체·품목·지역의 판매금액, 제품판매중량, 평균단가, 증감 | 인수처 식별 |
| 전년·당해 인수처 파일 12개 | 인수처별 판매금액·제품판매중량·평균단가, 전년 실적 존재 여부, 신규·재개·미출고, 월별 추이, 인수처 구성 변화 | 전체 KPI, 평균단가, 공식표 검산 |
| 사업계획대비매출실적분석 | 누계파일 계산값의 공식 검산 | 인수처별 원인 추정 |

인수처 파일 합계가 공식 실적과 달라도 전체 KPI를 수정하거나 경고하지 않습니다. 인수처 파일은 어느 인수처향 실적이 증가·감소했는지 확인하는 용도로만 사용합니다.

## 2. 누계파일 집계

- 판매금액: `계정 6`을 제외합니다.
- 내수 금액: `한국원화금액 ÷ 1,000,000`으로 백만원 환산합니다.
- 수출 금액: `달러금액 ÷ 1,000`으로 천달러 환산합니다.
- 제품판매중량: `계정 6`과 `레벨1명`의 `상품` 분류를 제외한 뒤 `중량 ÷ 1,000`으로 톤 환산합니다.
- 음수 실적은 반품·취소 가능성이 있으므로 그대로 합산합니다.

```text
평균단가 = 판매금액 / 제품판매중량
증감액 = 당기 - 기준
증감률 = 당기 / 기준 - 1
중량 효과 = (당기 중량 - 기준 중량) × 기준 평균단가
단가·구성 효과 = 판매금액 증감액 - 중량 효과
```

내수는 `백만원 ÷ 톤 = 천원/kg`, 수출은 `천달러 ÷ 톤 = 달러/kg`입니다. `단가·구성 효과`에는 실제 가격뿐 아니라 제품·규격·지역 구성 변화도 포함될 수 있습니다.

## 3. 품목과 지역 기준

- 합섬 내수·수출: 레벨1명 → 레벨2명 순으로 분석합니다.
- 스텐 내수·수출: 레벨1명 → 레벨2명 순으로 분석합니다.
- 제강 내수·수출: 레벨2명까지만 품목으로 분석하고, 해당 레벨2명에서 바로 인수처·전년 누계·월별 추이로 연결합니다. 레벨3명은 보고문안의 품목 분류에 사용하지 않습니다.
- `SPECIAL ROPE 1`, `SPECIAL ROPE 2`는 `SR1`, `SR2`로 표시합니다.
- 수출 지역은 누계파일의 `담당자명`을 사용합니다.

## 4. 인수처 기준

- 한 파일에 피벗·세부 정보·원자료 시트가 함께 있으면 필수 열을 갖춘 시트 중 분석 대상 연도의 실제 거래행이 가장 많은 원자료 시트를 선택합니다. 동률이면 `Raw data` 시트를 우선합니다.
- 인수처 파일의 금액·중량 단위는 해당 연도의 공식 누계와 대조해 원/백만원, 달러/천달러, kg/톤을 판별합니다. 이미 백만원·천달러·톤인 자료는 다시 나누지 않습니다.
- `인수처명`이 있으면 인수처명을 사용합니다.
- 인수처명이 비어 있을 때만 거래처명을 사용합니다.
- `현대삼호중공업(주)`와 `에이치디현대삼호㈜`는 동일 인수처로 통합합니다. 다른 회사의 구·신명칭은 자동 통합하지 않습니다.
- 계정 6은 제외합니다.
- 전월 대비와 전년 동기 누계를 각각 비교합니다.
- 인수처별 제품판매중량은 자동 판별한 원자료 단위에 따라 톤으로 환산하며, 상품 분류는 누계파일과 동일하게 제품판매중량에서 제외합니다.
- 합섬·스텐 인수처 증감은 `레벨1명 + 레벨2명 + 인수처`로 묶고, 제강은 `레벨2명 + 인수처`로 묶어 품목 증감과 해당 인수처를 직접 연결합니다.
- 2025년과 2026년의 월별 금액을 함께 표시해 전년 실적 존재 여부를 확인합니다.
- 신규·재개·미출고·기저효과는 숫자 패턴으로 분류하며 사업 원인을 확정하는 표현이 아닙니다.
- 제강 CONTROL CABLE은 누계파일 기준 전체·품목 분석에는 포함하되, 인수처 파일의 품목 분류 이슈로 인수처별 분석에서만 제외합니다.

## 5. 공식표 검산

6개 부문마다 다음 8개 항목을 누계파일 계산값과 공식 실적표로 비교합니다.

1. 전월 판매금액
2. 전월 제품판매중량
3. 당월 판매금액
4. 당월 제품판매중량
5. 전년 동기 누계 판매금액
6. 전년 동기 누계 제품판매중량
7. 당해 누계 판매금액
8. 당해 누계 제품판매중량

허용 오차는 기본 0.1%이며 `config/analysis_rules.yaml`에서 변경할 수 있습니다. `WARN`이 있으면 계정·상품 제외 기준 또는 공식표 수식을 확인해야 합니다.

## 6. 보고문안 사용

- 자동 문안은 전월 대비와 누계를 분리합니다.
- 주요 상위 분류는 전체 품목 변동의 약 80%가 설명될 때까지 최대 4개를 선택하며, 금액 기준이 작더라도 증가·감소 방향을 대표하는 품목은 포함할 수 있습니다.
- 합섬·스텐 하위 분류는 상위 분류 변동을 주도하거나 의미 있게 상쇄한 항목만 최대 2개를 선택합니다. 제강은 레벨3 하위 분류를 표시하지 않습니다.
- 인수처는 합섬·스텐은 선택한 하위 분류별, 제강은 레벨2 품목별 핵심 증가·감소 인수처를 우선 표시하고 전년 동기 누계와 당해 누계를 함께 비교합니다.
- 월별 금액 전체 나열은 신규·재개·미출고·고변동 등 예외 패턴에만 사용하며, 일반적인 연속·간헐 출고는 한 문장으로 축약합니다.
- 전월 대비 품목 순증감이 작더라도 인수처별 증가합계와 감소합계가 모두 기준금액 이상이고 서로 상당 부분 상쇄되면 `인수처 구성 변화`로 별도 표시합니다. 기본값은 양 방향 각각 100백만원/천달러 이상, 총 변동 250백만원/천달러 이상, 작은 방향이 큰 방향의 35% 이상, 순증감이 총 변동의 35% 이하입니다.
- 구성 변화 문안은 품목별 최대 2개, 증가 인수처 최대 3개, 감소 인수처 최대 2개로 제한합니다.
- 동일 인수처의 판매금액과 제품판매중량이 반대로 움직이고 평균단가 변동률이 10% 이상이면 물량보다 평균단가 또는 제품 구성 변화가 작용했을 가능성을 표시합니다.
- 문안은 합섬·스텐은 상위 분류의 금액·중량·평균단가에서 시작해 하위 분류와 해당 인수처로 내려가고, 제강은 레벨2 품목의 금액·중량·평균단가에서 해당 인수처로 바로 연결한 뒤 전년·당해 흐름, 수출 지역, 종합 결론 순으로 작성합니다.
- 향후 출고계획과 영업 현장 확인 내용은 자동 산출값과 섞지 말고 별도로 추가합니다.
- 일회성 수주, 가격 인상, 프로젝트 종료 등은 원자료만으로 단정하지 않습니다.
