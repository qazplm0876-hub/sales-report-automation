# 월간 실행 체크리스트

## 1. 폴더 준비

- [ ] `data\2026-06\input` 폴더 준비
- [ ] `data\2026-06\input\customers` 폴더 준비
- [ ] `data\2026-06\output` 폴더 확인

## 2. 입력 파일 준비

- [ ] 당월 템플릿 파일 준비
- [ ] 당해 raw 파일 준비: 예 `20266월누계.xlsx`
- [ ] 전년 raw 파일 준비: 예 `20256월누계.xlsx`
- [ ] 월별 사업계획 파일 준비
- [ ] 제품판매량 사업계획 파일 준비
- [ ] 해외현지내수판매계획 파일 준비
- [ ] DSR 손익 파일 준비. 없으면 섹션4만 스킵됨
- [ ] 제강 손익 파일 준비. 없으면 섹션4만 스킵됨

## 3. END USER 파일 준비

아래 파일은 `data\2026-06\input\customers`에 넣습니다.

- [ ] `1.xlsx`: 합섬 수출 END USER
- [ ] `2.xlsx`: 스텐 수출 END USER
- [ ] `3.xlsx`: 제강 수출 END USER
- [ ] `1_내수.xlsx`: 합섬 내수 END USER. 있으면 반영
- [ ] `2_내수.xlsx`: 스텐 내수 END USER. 있으면 반영
- [ ] `3_내수.xlsx`: 제강 내수 END USER. 있으면 반영

## 4. 실행

- [ ] `run_monthly_report.bat` 더블클릭
- [ ] 보고서 대상 월 입력. 예: `6`

## 5. 결과 확인

결과 위치:

```text
data\2026-06\output
```

- [ ] 완성 엑셀 생성 여부 확인
- [ ] 검증 PDF 생성 여부 확인
- [ ] 코멘트 MD 생성 여부 확인
- [ ] 검증 리포트의 차이 항목 확인
- [ ] 수동 입력 항목 반영

## 6. 코멘트 검토

- [ ] 수출 코멘트에 품목별 증감이 보이는지 확인
- [ ] 주요 지역의 증감 원인이 설명되어 있는지 확인
- [ ] 수출 코멘트에 END USER가 필요한 곳에 표시되는지 확인
- [ ] 내수 END USER 파일이 있으면 내수 코멘트에도 END USER가 표시되는지 확인
