# 월간 실행 체크리스트

## 1. 파일 준비

- [ ] 당월 템플릿 파일 준비
- [ ] 당해 raw 파일 준비
- [ ] 전년 raw 파일 준비
- [ ] DSR 손익 파일 준비
- [ ] 제강 손익 파일 준비
- [ ] 계획 파일 3종 확인
- [ ] 수출 거래처 파일 `1.xlsx`, `2.xlsx`, `3.xlsx` 준비

## 2. 실행 전 확인

- [ ] `monthly_report_final.py`의 `MONTH` 값이 보고서 작성월과 일치하는지 확인
- [ ] 파일명이 스크립트 규칙과 일치하는지 확인
- [ ] 엑셀 잠금 파일 `~$...xlsx`가 있으면 실제 파일이 열려 있는지 확인

## 3. 실행

```powershell
python monthly_report_final.py
```

## 4. 결과 확인

- [ ] 완성 엑셀 생성 여부 확인
- [ ] 검증 PDF 생성 여부 확인
- [ ] 코멘트 MD 생성 여부 확인
- [ ] 검증 리포트의 차이 항목 확인
- [ ] 수동 입력 항목 반영

## 5. 코멘트 검토

- [ ] 수출 코멘트에 품목군별 증감이 있는지 확인
- [ ] 주요 지역/담당 증감 원인이 설명되어 있는지 확인
- [ ] 거래처명은 수출에만 표시되는지 확인
- [ ] 내수는 기존 수준의 요약 코멘트인지 확인
