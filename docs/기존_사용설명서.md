# 월별 사업계획대비 매출실적 분석 자동화 사용설명서

## 개요
매월 반복되는 매출실적분석 파일 작성을 자동화한 스크립트입니다.  
`MONTH` 값 하나만 바꾸면 섹션1~4 대부분을 자동으로 채워줍니다.

---

## 필요 환경
```bash
pip install openpyxl xlrd pandas
```

---

## 매월 준비할 파일 목록

| 파일명 규칙 | 설명 |
|---|---|
| `사업계획대비_매출실적분석_26년_{N}월_.xlsx` | 템플릿 (전달 완성본도 OK) |
| `월별_사업계획.xlsx` | 연간 매출 계획 (변동 없으면 재사용) |
| `제품판매량_사업계획.xlsx` | 제품별 판매량 계획 (변동 없으면 재사용) |
| `2_해외현지내수판매계획_청도_비나_DCV_.xlsx` | 청도/비나 현지내수 계획 (변동 없으면 재사용) |
| `2026{N}월누계.xls` | 당해 raw data (예: `20265월누계.xls`) |
| `2025{N}월누계.xls` | 전년 raw data (예: `20255월누계.xls`) |
| `DSR_{N:02d}_상원.xlsx` | DSR 합섬/스텐 포괄손익 (예: `DSR_05_상원.xlsx`) |
| `제강{N:02d}_상원.xlsx` | 제강 포괄손익 (예: `제강05_상원.xlsx`) |

> 모든 파일은 스크립트와 **같은 폴더**에 위치해야 합니다.

## 사용법

### 1. MONTH 설정
`monthly_report_final.py` 상단에서 월 변경:
```python
MONTH = 5   # ← 여기만 수정
```

### 2. 실행
```bash
python3 monthly_report_final.py
```

### 3. 출력 파일 확인
```
사업계획대비_매출실적분석_26년_5월_완성_CLAUDE.xlsx
```

## 자동화 범위

### 섹션1. 전체매출실적
| 열 | 내용 | 출처 |
|---|---|---|
| C (전월) | 전월 실적 | 당해 raw data (요청월 필터) |
| D (당월계획) | 당월 계획 | 월별_사업계획.xlsx |
| E (당월실적) | 당월 실적 | 당해 raw data (당월 필터) |
| H (전년실적) | 전년 누계 | 전년 raw data |
| I (당해계획) | 당해 누계계획 | 월별_사업계획.xlsx |
| J (당해실적) | 당해 누계실적 | 당해 raw data 전체 |

### 섹션2. 제품판매량
- 합섬/스텐/제강 수출·내수·청도·비나 중량
- 제강 품목별: WR/C/C/G/S/WIRE/OT/IT
- **합섬상품·스텐상품 제외**, 청도제강은 스틸상품 포함

### 섹션3. 제품판매단가
- 합섬(수출/내수), 스텐(수출/내수), 제강(수출/내수), 청도/비나
- 단가 = 누적금액 ÷ 누적중량
- 수출: 달러/kg / 내수·현지: 천원/kg
- 청도·비나 I열(당해계획)은 해외계획파일 환율 변환값
  - 청도: 1 CNY = 200원
  - 비나/DCV: 100 VND = 5.5원

### 섹션4. 통합손익요약
| 열 | 내용 | 출처 |
|---|---|---|
| C (전월) | 전월 매출/영업이익 | DSR/제강 상원 파일 |
| D (당월실적) | 당월 매출/영업이익 | DSR/제강 상원 파일 |
| F (전년실적) | 전년 1~N월 누계 | DSR/제강 상원 파일 |
| G (당해실적) | 당해 1~N월 누계 | DSR/제강 상원 파일 |

> 이익율(E, H열)은 파일 내 수식으로 자동계산됩니다.

## 수동 입력 항목
스크립트 실행 후 아래 항목은 직접 입력 필요:

| 항목 | 위치 | 출처 |
|---|---|---|
| 기타매출 당월실적 | 섹션1 행33~35 E열 | 별도 자료 |
| 기타매출 전년실적 | 섹션1 행33~35 H열 | 별도 자료 |
| 기타매출 당해실적 | 섹션1 행33~35 J열 | 별도 자료 |

## raw data 전처리 규칙
스크립트 내부에서 자동 처리되는 항목:
- D열(회사) = `'6'` 행 제거
- AB열(계정) = `'6'` 행 제거
- AD열(원화금액) 삭제
- 중량 ÷ 1,000 (단위: ton)
- 달러금액 ÷ 1,000 (단위: 천달러)
- 한국원화금액 ÷ 1,000,000 (단위: 백만원)

## 제품 분류 기준

### 합섬 (레벨1명 기준)
- **포함**: 합섬기타, 합섬방사, 합섬비방사, 합섬웨빙, 합섬특수
- **제외**: 합섬상품 (수출/내수/청도 모두)

### 스텐 (레벨1명 기준)
- **포함**: 스텐로프, 스텐선재
- **제외**: 스텐상품

### 제강 (레벨1명 + 레벨2명 기준)
| 품목 | 레벨1명 | 레벨2명 |
|---|---|---|
| WR | 스틸로프 | WIRE ROPE, SPECIAL ROPE 1, SPECIAL ROPE 2 |
| C/C | 스틸로프 | CONTROL CABLE |
| G/S | 스틸ＳＴ | GUY STRAND |
| WIRE | 스틸선재 | WIRE |
| OT | 스틸선재 | OT WIRE |
| IT | 스틸선재 | IT WIRE |

- **수출/내수**: 스틸로프 + 스틸선재 (스틸상품 제외)
- **청도 제강**: 스틸로프 + 스틸선재 + **스틸상품 포함**
- **비나 제강**: 스틸로프 + 스틸선재

### 비나 집계 범위
- DSR VINA-현지내수
- CABLE VINA-내수
- CABLE VINA-수출

## 검증 리포트
실행 시 자동으로 출력됩니다:
- **섹션1**: 소계 셀값 vs 합섬+스텐+제강 수동합산 비교
- **섹션4**: 통합 vs 한국+중국+비나 합산 비교
- `✓` = 정상 / `✗` = 차이 있음 → 확인 필요

## 주의사항
1. 파일명이 정확히 일치해야 합니다 (공백, 특수문자 주의)
2. 분기 넘어가는 달(7월, 10월)은 계획파일 행번호가 자동 계산됩니다
3. 출력 파일명 뒤에 `_CLAUDE`가 붙습니다
