# 코멘트 작성 기준

## 기본 출력과 상세 출력

- 기본 `코멘트_N월`은 팀장 브리핑용 문장형 보고서로 생성한다.
- `코멘트_N월_상세`는 기존의 소제목·목록형 진단 보고서로 생성한다.
- 기본 보고서는 전월 비교 후 전년 동월 누계 비교를 함께 표시한다.
- 매출·판매량·평균단가·가격/믹스는 공식 Raw만 사용한다.
- 거래처 상세파일은 END USER 증감액과 거래 이력 판단에만 사용한다.
- 평균단가만으로 가격 인상 또는 제품믹스 개선을 단정하지 않는다.
  가격효과·믹스효과 분해 결과가 있을 때만 구체 원인을 표현한다.

## 기본 브리핑 흐름

1. 전월 대비 부문 전체 매출 증감
2. 전년 1~N월 대비 당년 1~N월 누계 매출·판매량·평균단가
3. 매출 증감액이 큰 품목의 물량·평균단가 해석
4. 평균단가 변동 기준을 넘은 품목의 가격·믹스 원인
5. END USER별 전월 대비 증감액
6. 전월·전년 거래 이력에 따른 신규·기존 거래처 판단

## 기본 방향

- 수출은 상세 분석한다.
- 내수는 기존 수준의 요약 분석을 유지한다.
- 수출/내수 상세 정보는 거래처명이 아니라 `인수처명`, 즉 END USER 기준으로 사용한다.
- 수출 END USER 파일은 `1.xlsx`, `2.xlsx`, `3.xlsx`를 사용한다.
- 내수 END USER 파일은 있으면 `1_내수.xlsx`, `2_내수.xlsx`, `3_내수.xlsx` 또는 `합섬_내수.xlsx`, `스텐_내수.xlsx`, `제강_내수.xlsx`를 사용한다.

## 수출 코멘트 흐름

1. 전월·당월 실적과 순증감
2. 품목군별 전월·당월 금액과 증감률
3. 주요 증가 요인과 당월 END USER
4. 주요 감소 요인과 전월 END USER
5. 주요 지역/담당 증감
6. 기저효과 또는 출고 공백 여부
7. 가장 큰 증가·감소 요인을 반영한 종합 해석

각 항목은 긴 문장 하나로 합치지 않고 별도 소제목과 목록으로 구분한다.
전월 실적이 0인 항목은 증가율 `100%` 대신 `신규 출고`로 표시한다.

## 주요 지역/담당 변화

- 지역 또는 담당자 전체의 전월·당월 금액과 순증감을 먼저 표시한다.
- 한 개의 핵심 품목만 선택하지 않고, 해당 지역 안에서 증감액이 큰 품목군을 최대 4개까지 함께 표시한다.
- 각 품목군 아래에는 변화를 설명하는 세부 품목을 최대 3개까지 표시한다.
- 증가 품목과 감소 품목이 함께 있으면 둘 다 표시하여 상쇄 관계를 알 수 있게 한다.
- 증감률이 30%를 넘거나 전체 실적 대비 증감액이 큰 지역을 주요 변화 대상으로 선정한다.

## 주요 증가 요인

- 전월 대비 증가액이 큰 `담당자/레벨1/레벨2` 조합을 우선 표시한다.
- 각 요인은 증가액, 증가율, 증가요인 내 비중을 함께 표시한다.
- `증가요인 내 비중`은 감소 항목을 제외하고, 전월 대비 증가한 항목들의 증가액 합계 중 해당 항목이 차지하는 비중이다.
- 상세 데이터가 있으면 해당 증가 요인의 당월 주요 END USER도 함께 표시한다.

## 주요 감소 요인

- 전월 대비 감소액이 큰 `담당자/레벨1/레벨2` 조합을 우선 표시한다.
- 각 요인은 전월·당월 금액, 감소액, 감소율, 감소요인 내 비중을 함께 표시한다.
- 상세 데이터가 있으면 해당 감소 요인의 전월 주요 END USER도 함께 표시한다.

## 주요 분류 메모

- `SUPERFLEX`: 합섬방사
- `SUPERMAX`: 합섬특수
- `슈퍼슬링`, `PET R/S`, `슈퍼웹`: 합섬웨빙

## 기저효과 판단

현재 기본 기준은 아래 두 조건을 모두 만족하는 경우입니다.

- 전전월 대비 전월 출고가 2배 이상 증가
- 당월 출고가 전월의 절반 이하로 감소

이 조건을 만족하지 않더라도 특정 거래처의 전월 출고가 당월에 빠진 경우는 `거래처 출고 공백`으로 설명합니다.
