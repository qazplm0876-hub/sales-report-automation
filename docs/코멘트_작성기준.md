# 코멘트 작성 기준

## 기본 방향

- 수출은 상세 분석한다.
- 내수는 기존 수준의 요약 분석을 유지한다.
- 수출 거래처 정보는 `1.xlsx`, `2.xlsx`, `3.xlsx` 기준으로만 사용한다.

## 수출 코멘트 흐름

1. 전체 전월대비 수준
2. 품목군별 증감
3. 주요 지역/담당 증감
4. 주요 거래처
5. 기저효과 또는 출고 공백 여부

## 주요 분류 메모

- `SUPERFLEX`: 합섬방사
- `SUPERMAX`: 합섬특수
- `슈퍼슬링`, `PET R/S`, `슈퍼웹`: 합섬웨빙

## 기저효과 판단

현재 기본 기준은 아래 두 조건을 모두 만족하는 경우입니다.

- 전전월 대비 전월 출고가 2배 이상 증가
- 당월 출고가 전월의 절반 이하로 감소

이 조건을 만족하지 않더라도 특정 거래처의 전월 출고가 당월에 빠진 경우는 `거래처 출고 공백`으로 설명합니다.
