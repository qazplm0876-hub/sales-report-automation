# 매출실적 분석 자동화

월별 매출실적 분석 보고서와 코멘트 초안을 생성하는 자동화 코드입니다.

## 매달 하는 일

1. 월별 입력 폴더를 만듭니다.

```text
data\2026-06\input
data\2026-06\input\customers
```

2. 해당 월 자료를 `input` 폴더에 넣습니다.

```text
data\2026-06\input
├─ 사업계획대비_매출실적분석_26년_6월_.xlsx
├─ 20266월누계.xlsx
├─ 20256월누계.xlsx
├─ 월별_사업계획.xlsx
├─ 제품판매량_사업계획.xlsx
├─ 2_해외현지내수판매계획_청도_비나_DCV_.xlsx
├─ DSR_06_상원.xlsx          # 없으면 섹션4만 자동 스킵
├─ 제강06_상원.xlsx          # 없으면 섹션4만 자동 스킵
└─ customers
   ├─ 1.xlsx                 # 합섬 수출 END USER
   ├─ 2.xlsx                 # 스텐 수출 END USER
   ├─ 3.xlsx                 # 제강 수출 END USER
   ├─ 1_내수.xlsx            # 합섬 내수 END USER, 있으면 반영
   ├─ 2_내수.xlsx            # 스텐 내수 END USER, 있으면 반영
   └─ 3_내수.xlsx            # 제강 내수 END USER, 있으면 반영
```

3. `run_monthly_report.bat`을 더블클릭합니다.

처음 실행할 때는 저장소 안에 전용 Python 환경인 `.venv`를 만들고 필요한 패키지를 자동으로 설치합니다. 이 과정에서만 인터넷 연결이 필요하며, 이후 실행부터는 설치된 환경을 그대로 사용합니다.

구형 Excel 원장인 `.xls`와 새 형식인 `.xlsx`를 모두 지원합니다. `.xls` 파일은 자동 설치되는 `xlrd`로 읽습니다.

4. 물어보는 창에 월을 입력합니다.

```text
6
```

5. 결과는 아래 폴더에 생성됩니다.

```text
data\2026-06\output
```

## 직접 실행

더블클릭 대신 터미널에서 실행할 수도 있습니다.

```powershell
python -m pip install -r requirements.txt
python monthly_report_final.py --month 6
```

`DSR_06_상원.xlsx`, `제강06_상원.xlsx`가 없으면 통합손익요약인 섹션4만 건너뜁니다.

본문의 섹션1~3, 검증 PDF, 코멘트 MD/PDF는 계속 생성됩니다.

## 제품판매량/제품판매단가 산출 로직

이 섹션은 보고서의 `2. 제품판매량`, `3. 제품판매단가`가 어떤 기준으로 채워지는지 정리한 내용입니다.

### 공통 Raw Data 전처리

Raw data는 `2026{월}월누계.xlsx`, `2025{월}월누계.xlsx`를 사용합니다.

- `회사`, `계정`, `요청월`은 문자로 변환 후 앞뒤 공백을 제거합니다.
- `회사 == 6`, `계정 == 6`인 행은 제외합니다.
- `중량`은 `kg` 단위 원자료를 `톤` 기준으로 보기 위해 `1,000`으로 나눕니다.
- `달러금액`은 `1,000`으로 나눠 `$K` 기준으로 사용합니다.
- `한국원화금액`은 `1,000,000`으로 나눠 `백만원` 기준으로 사용합니다.
- 실적은 기본적으로 `부문`, `내수/수출`, `레벨1명`, `레벨2명` 조건으로 필터링합니다.

### 제품판매량 기본 계산식

제품판매량 실적은 raw data의 `중량` 합계입니다.

```text
제품판매량 = 조건에 맞는 raw data 중량 합계
```

보고서 열별 기준은 아래와 같습니다.

```text
C열 전월     = 당해 raw 중 요청월이 전월인 데이터
E열 당월     = 당해 raw 중 요청월이 당월인 데이터
H열 전년     = 전년 raw 전체 누계 데이터
J열 당해     = 당해 raw 전체 누계 데이터
```

D열 당월계획, I열 당해계획은 raw data가 아니라 `제품판매량_사업계획.xlsx`에서 가져옵니다.

### 제품판매량: 합섬/스텐 기준

합섬 판매량은 아래 `레벨1명`을 묶어서 계산합니다.

```text
합섬기타
합섬방사
합섬비방사
합섬웨빙
합섬특수
```

스텐 판매량은 raw data의 `부문 = STS` 기준이며, 아래 `레벨1명`을 묶어서 계산합니다.

```text
스텐로프
스텐선재
```

보고서에서는 표시명을 `스텐`으로 쓰지만 raw data에서는 `STS`로 들어오는 경우가 있어 코드에서 `STS`를 기준으로 조회합니다.

### 제품판매량: 제강 WR/C-C/G-S/WIRE/OT/IT 기준

제강 판매량은 raw data에서 `부문 = 제강`을 기준으로 하며, `레벨1명`과 `레벨2명` 조합으로 세부 품목을 나눕니다.

| 보고서 품목 | Raw data 조건 |
| --- | --- |
| WR | `레벨1명 in [스틸로프, 스틸선재]` and `레벨2명 in [WIRE ROPE, SPECIAL ROPE 1, SPECIAL ROPE 2]` |
| C/C | `레벨1명 in [스틸로프, 스틸선재]` and `레벨2명 = CONTROL CABLE` |
| G/S | `레벨2명 = GUY STRAND` |
| WIRE | `레벨1명 in [스틸로프, 스틸선재]` and `레벨2명 = WIRE` |
| OT | `레벨1명 in [스틸로프, 스틸선재]` and `레벨2명 = OT WIRE` |
| IT | `레벨1명 in [스틸로프, 스틸선재]` and `레벨2명 = IT WIRE` |

주의할 점:

- 수출 G/S는 `내수/수출 in [수출, 내수]`, `레벨1명 = 스틸ＳＴ`, `레벨2명 = GUY STRAND`까지 포함해 합산합니다.
- 내수 G/S는 `레벨1명 in [스틸로프, 스틸선재]` 조건과 `레벨1명 = 스틸ＳＴ` 조건을 둘 다 더합니다.
- `스틸ＳＴ`는 영문 ST가 아니라 전각 문자 `ＳＴ`가 들어간 값이므로 raw data 표기를 그대로 맞춰야 합니다.

### 제품판매량: 해외법인 기준

해외법인은 raw data의 `내수/수출` 값으로 구분합니다.

| 보고서 항목 | Raw data 조건 |
| --- | --- |
| 청도 합섬 | `부문 = 합섬`, `내수/수출 = 청도DSR-현지내수`, `레벨1명 in [합섬기타, 합섬방사, 합섬비방사, 합섬웨빙, 합섬특수]` |
| 청도 제강 | `부문 = 제강`, `내수/수출 = 청도DSR-현지내수`, `레벨1명 in [스틸로프, 스틸선재, 스틸상품]` |
| 비나 합섬 | `부문 = 합섬`, `내수/수출 in [DSR VINA-현지내수, CABLE VINA-내수, CABLE VINA-수출]` |
| 비나 제강 | `부문 = 제강`, `내수/수출 in [DSR VINA-현지내수, CABLE VINA-내수, CABLE VINA-수출]` |

### 제품판매단가 기본 계산식

제품판매단가는 raw data의 금액을 중량으로 나누어 계산합니다.

```text
제품판매단가 = 조건에 맞는 금액 합계 / 조건에 맞는 중량 합계
```

수출과 내수의 금액 기준은 다릅니다.

```text
수출 단가 = 달러금액 / 중량
내수 단가 = 한국원화금액 / 중량
```

보고서 열별 기준은 아래와 같습니다.

```text
C열 전전월   = 당해 raw 중 요청월이 전전월인 데이터
D열 전월     = 당해 raw 중 요청월이 전월인 데이터
E열 당월     = 당해 raw 중 요청월이 당월인 데이터
H열 전년     = 전년 raw 전체 누계 데이터
J열 당해     = 당해 raw 전체 누계 데이터
```

I열 당해계획 단가는 raw data가 아니라 `제품판매량_사업계획.xlsx` 기준으로 계산합니다.

```text
계획 단가 = 제품판매량_사업계획의 누적금액 / 누적중량
```

### 제품판매단가: 합섬 방사/비방사/웨빙/특수 기준

합섬 단가는 raw data의 `레벨1명` 기준으로 나눕니다.

| 보고서 품목 | Raw data 조건 |
| --- | --- |
| 방사 | `부문 = 합섬`, `레벨1명 = 합섬방사` |
| 비방사 | `부문 = 합섬`, `레벨1명 = 합섬비방사` |
| 웨빙 | `부문 = 합섬`, `레벨1명 = 합섬웨빙` |
| 특수 | `부문 = 합섬`, `레벨1명 = 합섬특수` |

`SUPERMAX`는 raw data의 `레벨2명`에는 제품명처럼 보이지만, 코멘트/분석 기준에서는 `레벨1명 = 합섬특수`에 속하는 품목으로 봅니다. 따라서 제품판매단가의 `특수`는 `SUPERMAX`만 따로 보는 것이 아니라 `레벨1명 = 합섬특수` 전체를 기준으로 계산합니다.

참고 분류:

```text
SUPERMAX  -> 합섬특수
SUPERFLEX -> 합섬방사
슈퍼슬링 / PET R/S / 슈퍼웹 -> 합섬웨빙
```

### 제품판매단가: 스텐 기준

스텐 단가는 raw data의 `부문 = STS` 기준으로 계산합니다.

| 보고서 품목 | Raw data 조건 |
| --- | --- |
| 로프 | `부문 = STS`, `레벨1명 = 스텐로프` |
| 선재 | `부문 = STS`, `레벨1명 = 스텐선재` |

수출은 `달러금액 / 중량`, 내수는 `한국원화금액 / 중량`을 사용합니다.

### 제품판매단가: 제강 기준

제강 단가는 판매량과 같은 `레벨1명`, `레벨2명` 기준을 사용하되 금액을 중량으로 나눕니다.

| 보고서 품목 | Raw data 조건 |
| --- | --- |
| WR | `레벨1명 = 스틸로프`, `레벨2명 in [WIRE ROPE, SPECIAL ROPE 1, SPECIAL ROPE 2]` |
| C/C | `레벨1명 = 스틸로프`, `레벨2명 = CONTROL CABLE` |
| G/S | `레벨1명 = 스틸ＳＴ`, `레벨2명 = GUY STRAND` |
| WIRE | `레벨1명 = 스틸선재`, `레벨2명 = WIRE` |
| OT | `레벨1명 = 스틸선재`, `레벨2명 = OT WIRE` |
| IT | `레벨1명 = 스틸선재`, `레벨2명 = IT WIRE` |

판매량의 WR은 `스틸로프`, `스틸선재`를 함께 허용하지만, 단가의 WR은 현재 코드상 `레벨1명 = 스틸로프` 기준으로 계산합니다. C/C도 단가에서는 `레벨1명 = 스틸로프` 기준입니다.

### 제품판매단가: 청도/비나 기준

청도/비나의 실적 단가는 raw data 기준입니다.

| 보고서 항목 | Raw data 조건 |
| --- | --- |
| 청도 합섬 | `부문 = 합섬`, `내수/수출 = 청도DSR-현지내수`, 합섬 전체 레벨1 기준 |
| 청도 제강 | `부문 = 제강`, `내수/수출 = 청도DSR-현지내수`, `레벨1명 in [스틸로프, 스틸상품]` |
| 비나 합섬 | `부문 = 합섬`, `내수/수출 in [DSR VINA-현지내수, CABLE VINA-내수, CABLE VINA-수출]`, 합섬 전체 레벨1 기준 |
| 비나 제강 | `부문 = 제강`, `내수/수출 in [DSR VINA-현지내수, CABLE VINA-내수, CABLE VINA-수출]`, `레벨1명 in [스틸로프, 스틸선재]` |

청도/비나의 계획 단가는 해외계획 파일에서 누적 중량과 누적 금액을 가져와 환율 계수를 곱해 계산합니다.

```text
청도 계획 단가 = 해외계획 금액 * 200 / 1,000,000 / 중량
비나 계획 단가 = 해외계획 금액 * 0.055 / 1,000,000 / 중량
```

## GitHub 관리 원칙

GitHub에는 자동화 코드와 설명서만 올립니다.

엑셀 원자료, END USER 상세 파일, 완성 보고서, PDF는 민감 자료이므로 `.gitignore`에서 제외합니다.
