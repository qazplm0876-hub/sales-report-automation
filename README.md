# 월간 매출실적 분석 자동화 v3.3.1

Windows에서 `input` 폴더에 월간 원자료를 넣고 `RUN_ANALYSIS.bat`을 실행하면 합섬·스텐·제강의 내수·수출 6개 부문 분석 엑셀과 보고용 줄글 초안을 생성합니다.

보고문안은 합섬·스텐은 레벨1명에서 레벨2명·인수처로 내려가고, 제강은 레벨2명에서 바로 인수처로 연결합니다. 인수처의 전년 동기·당해 누계와 예외적인 월별 출고 흐름을 함께 확인하며, 수출 부문은 지역별 금액·중량·평균단가 변화도 분석합니다. 품목 순증감이 작아도 인수처별 증가·감소가 동시에 큰 경우에는 구성 변화로 별도 표시하고, 금액과 중량이 반대로 움직이면 평균단가·제품 구성 변화 가능성까지 제시합니다.

```text
input/원자료 9개(통합형 권장 구성)
    ↓ RUN_ANALYSIS.bat
output/YYYYMM/YYYYMM_매출실적_분석.xlsx
output/YYYYMM/YYYYMM_보고용_초안.md
```

## 1. 처음 설치

Windows 10/11과 Python 3.10 이상을 권장합니다.

1. 폴더를 `C:\Work\sales-report-automation`처럼 짧은 경로에 둡니다.
2. Python을 설치할 때 `Add python.exe to PATH`를 선택합니다.
3. `INSTALL.bat`을 한 번 실행합니다.
4. 이후에는 매달 `RUN_ANALYSIS.bat`만 실행합니다.

`RUN_ANALYSIS.bat`은 실행에 필요한 패키지가 빠져 있으면 `INSTALL.bat`을 자동으로 다시 실행합니다.

## 2. 입력파일

### 권장 구성: 총 9개

- 사업계획대비매출실적분석 공식표 1개
- 전년 누계파일 1개: 예 `20257월누계.xlsx`
- 당해 누계파일 1개: 예 `20267월누계.xlsx`
- 전년·당해 거래가 함께 있는 인수처 통합 파일 6개
  - 합섬 수출·내수 각 1개
  - 스텐 수출·내수 각 1개
  - 제강 수출·내수 각 1개

예: `거래처 정보 포함 25-26 제강(내수).xlsx`처럼 한 파일 안에 2025년과 2026년 거래가 모두 있으면 됩니다. 파일명은 고정하지 않으며, 내부의 연도·부문·내수/수출 구조로 자동 판별합니다.

매월 공식표·전년 누계파일·당해 누계파일·인수처 통합 파일 6개를 해당 분석월 기준 최신 자료로 교체합니다.

### 기존 분리형도 지원: 총 15개

인수처 파일을 전년 6개와 당해 6개로 나누어 넣는 방식도 사용할 수 있습니다.

- 당해 인수처 파일
  - `1.xlsx`, `1_내수.xlsx`: 합섬 수출·내수
  - `2.xlsx`, `2_내수.xlsx`: 스텐 수출·내수
  - `3.xlsx`, `3_내수.xlsx`: 제강 수출·내수
- 전년 인수처 파일
  - `25_1.xlsx`, `25_1_내수.xlsx`
  - `25_2.xlsx`, `25_2_내수.xlsx`
  - `25_3.xlsx`, `25_3_내수.xlsx`

2027년 분석처럼 연도가 바뀌면 전년 파일도 `26_1.xlsx` 형식으로 교체합니다. 파일명보다 내부 연도·부문·내수/수출 구조를 우선 판별하므로 `2025_1_수출.xlsx`처럼 연도가 포함된 이름도 사용할 수 있습니다.

통합형과 분리형을 같은 부문에 함께 넣으면 중복 입력으로 처리되므로 둘 중 하나만 사용합니다. 피벗·세부 정보·원자료 시트가 함께 있으면 분석 대상 연도의 거래행이 가장 많은 원자료 시트를 자동 선택합니다.

## 3. 자료 역할

| 자료 | 역할 |
|---|---|
| 누계파일 2개 | 전체·품목·지역의 금액, 중량, 평균단가 계산 |
| 인수처 통합 파일 6개 또는 분리 파일 12개 | 인수처별 금액·중량·평균단가 증감, 전년 실적 존재 여부, 월별 추이, 인수처 구성 변화 |
| 공식 실적표 | 누계파일 계산값 검산 |

인수처 파일은 전체 KPI와 평균단가 계산에 사용하지 않습니다. 따라서 인수처 파일 합계가 공식표와 달라도 그 차이를 전체 수치에 섞지 않습니다.

인수처 파일의 금액·중량 단위는 공식 누계와 대조해 자동 판별합니다. 원·달러·kg 원자료는 보고단위로 환산하고, 이미 백만원·천달러·톤으로 저장된 자료는 다시 나누지 않습니다. 인수처 별칭은 `현대삼호중공업(주)`와 `에이치디현대삼호㈜`만 통합합니다.

## 4. 매월 실행

1. `input`에서 지난달 자료를 빼고 이번 달 공식표·전년 누계파일·당해 누계파일·인수처 통합 파일 6개를 넣습니다.
2. 분리형을 사용하는 경우 전년 인수처 파일 6개는 그대로 두고 당해 인수처 파일 6개만 교체합니다.
3. `RUN_ANALYSIS.bat`을 실행합니다.
4. 분석월은 비워 두고 Enter를 누르면 공식표 제목에서 자동 인식합니다.
5. `output\YYYYMM`의 엑셀과 Markdown 문안을 확인합니다.
6. 엑셀 `검산` 시트의 `WARN`을 먼저 확인합니다.

## 5. 결과 시트

| 시트 | 내용 |
|---|---|
| 요약 | 전월·누계 금액, 제품판매중량, 평균단가, 중량 효과, 단가·구성 효과 |
| 자료역할 | 입력자료별 사용·제외 용도 |
| 검산 | 누계파일 계산값과 공식표 48개 항목 비교 |
| 품목증감·세부품목 | 누계파일 기준 품목별 증감. 세부품목 시트는 합섬·스텐만 표시 |
| 인수처증감 | 합섬·스텐은 상위·하위품목별, 제강은 레벨2 품목별 주요 인수처와 전년 실적 여부 |
| 인수처구성변화 | 순증감 대비 내부 증가·감소가 큰 품목과 주요 증가·감소 인수처, 금액·중량 역행 사례 |
| 지역증감 | 누계파일 기준 수출 지역별 증감 |
| 인수처월별추이 | 합섬·스텐은 상위·하위품목별, 제강은 레벨2 품목별 전년·당해 월별 인수처 판매금액 |
| 추가확인사항 | 단가 급변, 신규·재개·미출고 등 확인 필요 항목 |
| 원본파일 | 자동 선택한 파일·연도·시트·자료 역할 |

상세 계산 규칙은 [docs/ANALYSIS_RULES.md](docs/ANALYSIS_RULES.md)를 참고합니다.

## 6. 개인 PC와 사무실 PC 동기화

코드만 비공개 GitHub 저장소로 동기화하고 원본·결과 엑셀은 각 PC에만 둡니다. `.gitignore`가 `input`, `output`, `logs` 및 Excel·PDF 파일을 제외합니다.

- 첫 PC: GitHub Desktop에서 이 폴더를 `Add local repository`한 뒤 비공개로 Publish
- 두 번째 PC: 저장소를 Clone한 뒤 `INSTALL.bat` 실행
- 이후 업데이트: GitHub Desktop의 Fetch/Pull 또는 `UPDATE_CODE.bat`

## 7. 테스트와 설정

- 테스트: `RUN_TESTS.bat`
- 분석 순서·표시명·경고 기준: `config\analysis_rules.yaml`
- 계산 기준 설명: `docs\ANALYSIS_RULES.md`

## 8. 보안

- 저장소는 반드시 비공개로 생성합니다.
- 원본 엑셀이나 생성 보고서를 `git add -f`로 올리지 않습니다.
- 회사 정책상 허용된 PC·저장소·클라우드만 사용합니다.
